ATELIER QUEEN - النسخة الجديدة

تشغيل محلي:
1) python -m venv venv
2) تثبيت المتطلبات: pip install -r requirements.txt
3) تشغيل: python app.py
4) افتح: http://127.0.0.1:5000

لوحة الإدارة:
 /admin
اسم المستخدم الافتراضي: admin
كلمة المرور الافتراضية محليًا: ChangeMe123!
غيّرها قبل النشر.

النشر على Render:
- ارفع محتويات المجلد إلى GitHub.
- في Render اختر New > Blueprint واربط المستودع.
- راجع متغيرات البيئة قبل النشر.
- افتح /admin لإدارة الموقع.

مهم جدًا:
النسخة الحالية تحفظ قاعدة البيانات SQLite والملفات المرفوعة محليًا. استضافة Render المجانية لا تضمن بقاء الملفات المحلية بعد إعادة التشغيل/النشر.
قبل استقبال عملاء فعليين، يجب ربط قاعدة بيانات دائمة وتخزين صور دائم (مثل PostgreSQL وSupabase Storage) واختبارهما.
